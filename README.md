# Field Notes

A self-contained Jekyll site — no external theme dependency. Every layout,
include, and style lives in this repo, so nothing breaks when an upstream theme
goes quiet. Built to run on GitHub Pages with zero build scripts.

## Design at a glance

- **Palette:** aged paper, warm ink, loden-green primary, oxblood accents.
- **Type:** EB Garamond for reading; IBM Plex Mono (uppercase, tracked) for
  catalog-card metadata labels.
- **Modes:** light / dark / auto, with a persistent toggle in the footer.
- **Reading width:** ~66-character measure for long-form comfort.

## Run it locally

```bash
bundle install
bundle exec jekyll serve
# open http://localhost:4000
```

The `github-pages` gem pins Jekyll and every plugin to the exact versions
GitHub Pages runs, so a clean local build means a clean deploy.

## Deploy on GitHub Pages

1. Push this repo to GitHub (e.g. `brettwagner/brettwagner.github.io`, or any
   repo with Pages enabled).
2. **Settings → Pages → Build and deployment → Source:** *Deploy from a branch*,
   branch `main`, folder `/ (root)`.
3. The `CNAME` file already points at `brettwagner.me`. Make sure your DNS has
   the GitHub Pages records for the apex domain, then tick **Enforce HTTPS**.

## Writing

Posts live in `_posts/` named `YYYY-MM-DD-title.md`.

```yaml
---
title: "Your title"
date: 2026-08-01 09:00:00 -0700
tags: [books, reflections]
toc: true      # optional — auto table of contents on posts with 2+ headings
---
```

- **Excerpts:** put `<!--more-->` where the home-page preview should stop, or
  let it truncate to `excerpt_length` words (set in `_config.yml`).
- **Title-less notes:** set `title: ""`. These render in full on the home page,
  IndieWeb note-style, instead of as a headline + excerpt.
- **Tags:** any tags you use appear automatically on `/tags/`, grouped and
  alphabetized. No per-tag files to maintain. (Want dedicated `/tags/books/`
  URLs later? Add a stub page per tag with a small tag layout — ask and I'll
  wire it up.)

Delete the three sample posts in `_posts/` when you're ready.

## Configure

Everything you'll touch is in `_config.yml`:

- `title`, `subtitle`, `description`, `author`, `url`
- `paginate` — posts per page
- `excerpt_length` — words before "Read more"
- `goatcounter_code` — your GoatCounter subdomain (see below)
- `me:` — your rel="me" identity links

Navigation lives in `_data/menu.yml`.

## Analytics (GoatCounter)

Set `goatcounter_code` in `_config.yml` to your subdomain only. If your
dashboard is `https://brettwagner.goatcounter.com`, the value is `brettwagner`.
Leave it blank to disable. The snippet lives in `_includes/analytics.html` and
only loads when a code is set.

## Self-hosting the fonts (optional)

Fonts currently load from Google Fonts (see `_includes/head.html`). To self-host:

1. Download EB Garamond and IBM Plex Mono `.woff2` files into `/assets/fonts/`.
2. Replace the `<link>` tags in `head.html` with `@font-face` rules pointing at
   those files.

## Structure

```
_config.yml          site settings
_data/menu.yml       navigation
_layouts/            default, home, post, page
_includes/           head, masthead, footer, analytics, post-nav, enhancements
_sass/               field-notes.scss (all styling)
assets/css/          Sass entrypoint
_posts/              your writing (+ 3 samples to delete)
index.html           paginated home
about.md · tags.html · 404.html
feed.json            JSON Feed (RSS/Atom generated by jekyll-feed at /feed.xml)
CNAME · robots.txt
```
